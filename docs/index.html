CommonHours

A self-hosted tool that publishes the operator's own short-form videos to their own TikTok account.

What it is

CommonHours is a small command-line program that a single creator runs on their own computer. It takes a video file and a caption from the creator's own machine and uploads them to that creator's TikTok account through the official Content Posting API.

It is not a service. There is no CommonHours server, no account to sign up for, and no shared infrastructure. Each person who uses it runs their own copy on their own hardware, authorizes their own TikTok account, and posts only their own videos.

What it does before it uploads

  • Checks the video against TikTok's duration, file size, container, codec and frame-rate requirements, so a file that would be rejected never gets sent.
  • Queries the Creator Info endpoint and honours what it returns: the privacy levels available to the account, and whether the creator has disabled comments, duet or stitch. Account settings take priority over the tool's own configuration.
  • Requires the creator to declare, before each post, whether the video is AI-generated or altered, whether it is branded content, and how any music in it is licensed. These are required fields with no defaults.
  • Records each upload locally so a repeated run cannot post the same file twice.

How your data is handled

Everything stays on the machine you run it on. The OAuth token is stored in a local file readable only by your user account. No data is sent anywhere except to TikTok's own API endpoints. There is no analytics, no telemetry, and no third party.

The full detail is in the privacy policy.

Source code

CommonHours is open source. The complete implementation, including every API call it makes, can be read at github.com/Rico36/ShortVideos.
